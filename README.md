# Autoproperty · investor presentation (published site)

The published Autoproperty investor presentation, served by Vercel:

- Norwegian: https://autoproperty-deck.vercel.app/no/
- English: https://autoproperty-deck.vercel.app/en/

slides, f for full screen.

repository and replaced on every publish, so do not edit files here: change the source and publish again.
