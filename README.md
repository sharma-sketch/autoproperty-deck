# Autoproperty · investor presentation (published site)

The published Autoproperty investor presentation:

| | Norwegian | English |
|---|---|---|

| Vercel | https://autoproperty-deck.vercel.app/no/ | https://autoproperty-deck.vercel.app/en/ |

Both play the English film and offer the PDF in their language. Press → or space to step through the slides, g for all
slides, f for full screen.

This repository holds only the built site and is what GitHub Pages serves. The film is not stored here: GitHub Pages could
not sync the 14 MB file, so these pages stream it from the Vercel site. The repository is generated from Autoproperty's
private deck repository and replaced on every publish, so do not edit files here: change the source and publish again.
